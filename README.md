# Dog-Story — Асинхронный многопользовательский игровой сервер

Высокопроизводительный backend-сервер на современном C++ для многопользовательской браузерной игры. Реализует логику игрового мира в реальном времени, REST API, асинхронную обработку сетевых соединений и сохранение состояния.

## 🛠 Технологический стек
* **Язык:** C++20
* **Сетевое взаимодействие:** Boost.Beast (HTTP/REST API), Boost.Asio (асинхронный ввод-вывод, многопоточный `io_context`)
* **Форматы данных и логирование:** Boost.JSON, Boost.Log
* **Сборка и деплой:** CMake, Conan, Docker

## ✨ Ключевые возможности
* **Асинхронная архитектура:** обработка клиентских запросов в пуле потоков без блокировок с использованием `boost::asio::strand` для синхронизации доступа к игровому состоянию.
* **Игровая механика:** обработка перемещения персонажей по картам, проверка коллизий со стенами и объектами, сбор и сдача предметов в базы, начисление очков.
* **REST API:** авторизация игроков, получение списка карт, управление игровыми действиями, просмотр таблицы рекордов.
* **Надежность:** структурированное логирование событий в формате JSON, корректное завершение работы при получении системных сигналов `SIGINT`/`SIGTERM` (Graceful Shutdown).
* **Контейнеризация:** готовый `Dockerfile` для быстрого развертывания сервера и раздачи статических файлов фронтенда.

## 🚀 Сборка и запуск

### Локальная сборка (Linux / CMake + Conan)
```bash
git clone https://github.com
cd cpp_dog_story
mkdir build && cd build

conan install .. --build=missing
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j\$(nproc)

./bin/game_server --config-file ../data/config.json --www-root ../static/
```

### Запуск через Docker
```bash
docker build -t dog-story-server .
docker run -d -p 8080:8080 --name dog-story dog-story-server
```
После запуска сервер доступен по адресу `http://localhost:8080`.
